# Clean Code LMS

The course has been reset to basic placeholders: one section, one subsection, one lesson, one quiz and a final quiz. The existing interface and colors are retained.

Edit course.json and synchronize the embedded lms-course-data JSON in index.html. Run node tests/course.test.cjs to verify the course schema and embedded data.

Progress is browser-local. The placeholder course has a separate ID so previous lesson completions do not appear in it.

The prior extracted source remains in docs/clean-code-extracted.txt for later content work; it is not loaded into the placeholder course.

Live site: https://pythonidaer.github.io/clean-code-lms/
